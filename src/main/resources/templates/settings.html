Configuración

Ayudas rápidas para el MVP (extensión + DB).

Extensión (LinkedIn)

  1. Abrí LinkedIn → Jobs.
  2. Abrí el detalle de una oferta (panel derecho).
  3. Click en la extensión → Capture.

Backend esperado por defecto: http://127.0.0.1:8081 → POST /plugins/scrape-current

Base de datos actual

PostgreSQL + pgvector es la base principal actual de Datalaburo. Las capturas se guardan en JOBS, los snapshots quedan en JOB_SNAPSHOTS y los vectores viven en document_embeddings. H2 queda solo como legado histórico/test.

Queries de verificación (PostgreSQL)

Ejecutá estas consultas en PostgreSQL para confirmar dónde se guardan las capturas:

select count(*) from jobs;
select count(*) from job_snapshots;
select count(*) from job_offers;
select owner_type, count(*) from document_embeddings group by owner_type;

select id, created_at, title, company, location
from jobs
order by created_at desc
limit 20;

Conteos actuales (desde backend):

  • en JOBS
  • en JOB_SNAPSHOTS
  • en JOB_OFFERS (legacy)

Legacy / no usar

JOB_OFFERS existe por una entidad legacy (JobOffer) y un controller legacy (/api/job-offers). El flujo real del plugin usa /plugins/scrape-current y guarda en JOBS.
